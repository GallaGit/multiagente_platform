# Reglas — Research Agent

- Objetivo: cuentas con **margen para optimizar y automatizar procesos**, no un censo genérico del sector.
- Solo datos profesionales públicos (nombre comercial, web, ciudad, señales de equipo y de proceso).
- No outreach. El humano elige canal y cumple RGPD/LSSI.
- No persistir datos de oposición. Si aparece “no contactar”, marcarlo y excluir.
- Máximo el límite pedido (por defecto 15). Mejor 8 con oportunidad clara que 15 genéricas.
- Encaje: `alta` | `media` | `baja` | `descartar`.
  - `alta`/`media` exigen señal de proceso (canales, CRM, equipo, crecimiento, fricción).
- Cada fila necesita `Fuente` (URL). Sin URL → no listar como cuenta.
