# Segmento — Servicers y grandes operadores

## Relevancia

Este segmento adicional incluye servicers, grandes redes, consultoras y operadores con procesos intensivos. No es un primer ICP recomendado, pero funciona como frontera de presupuesto y complejidad.

## Perfil y tamaño

| Variable | Evidencia |
|---|---|
| Clientes | Bancos, fondos de deuda y grandes propietarios |
| Ingreso | Fee base + cobro, recuperación, hitos o venta |
| Contratos | Largos, con SLA |
| Tamaño | Típicamente mediano/grande; sin censo español segmentario |
| Referencia | doValue 2025: 136.000 M€ GBV global y 580,4 M€ ingresos |
| Oficinas/operaciones ES | NP |

La referencia global no se extrapola a España ni se interpreta como tarifa.

## Digitalización y stack

**Nivel:** alto.

CRM/servicing core, ERP, DMS/ECM, KYC/AML, BI/data warehouse, IAM/SSO, automatización, integraciones y desarrollos propios. IA emergente en grandes empresas.

## Problemas y oportunidades

- P13–P15 expedientes, AML y datos.
- P19–P21 integración/reporting; P24 seguridad; P29 continuidad.
- H4 compliance; H5 dinero; H6 analítica; H8 identidad.

**Urgencia:** alta, especialmente contractual y regulatoria.

## Capacidad económica

**Alta**, pero con ventas enterprise, requisitos de seguridad, implantación y procurement. Presupuesto público comparable: **NP**.

## Madurez organizativa

Procesos definidos, SLAs, auditoría, equipos TI/datos y gobierno. Disposición al cambio existe si el caso económico y riesgo están demostrados; no implica compra rápida.

## Barreras de compra

Ciclo largo, integraciones profundas, seguridad, homologación, legal, migración, continuidad, competencia de desarrollo interno y coste alto de adquisición.

## DMU probable

Operaciones detecta; TI/arquitectura, seguridad, compliance y usuarios evalúan; sponsor ejecutivo, finanzas y compras aprueban; apoderado firma; equipos operativos usan.

## Validación

**Confianza:** media en arquitectura; baja en compra.  
**Evidencia:** stack de gran empresa, modelo servicer y problemas de compliance/datos.  
**Limitaciones:** benchmark global y ausencia de datos españoles.  
**Pendiente:** tamaño mínimo de contrato, RFP, requisitos y duración de integración.
