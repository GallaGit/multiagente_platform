**Comprobación:** este índice normaliza las URLs citadas en las fichas; **no afirma una comprobación HTTP en tiempo real**. `Dinámico` indica contenido que puede cambiar, requerir sesión o devolver una versión distinta. `s. f.` indica documento sin fecha visible en la ficha.

## Reglas de mantenimiento

1. Mantener una URL canónica por estudio, norma o expediente; conservar varias solo si llevan a documentos funcionalmente distintos.
2. Al actualizar una ficha, añadir o retirar aquí el ID asociado y reflejar el mismo cambio en `Bibliografia.md`.
3. Registrar fecha de consulta en reseñas, tablas dinámicas, repositorios, páginas sin fecha, contenido social y documentación de producto.
4. Marcar `posible paywall`, `acceso dinámico`, `reseñas variables` o `s. f.` sin inferir disponibilidad HTTP.
5. Tratar Capterra, GetApp y Software Advice como una sola familia para independencia; no sumar sus páginas como corroboraciones separadas.
6. No promover Reddit, comentarios o reseñas a evidencia principal ni derivar prevalencia de ellos.
7. Si una URL cambia, conservar el título y el ID, sustituir por la ruta oficial más directa y registrar la fecha de la revisión.
