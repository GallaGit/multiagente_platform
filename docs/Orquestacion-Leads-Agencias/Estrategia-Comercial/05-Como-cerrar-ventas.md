# 05 — Cómo cerrar ventas

## Qué significa cerrar

Cerrar no es conseguir un “sí” verbal. Es lograr un compromiso verificable con:

- problema y alcance;
- resultado y métrica;
- champion y aprobador;
- precio y presupuesto;
- condiciones técnicas y legales;
- fechas, responsables y firma.

En fase inicial, el cierre recomendado es un **piloto pagado**, no una suscripción anual amplia sin evidencia.

## Puertas de calificación

No enviar propuesta hasta confirmar:

| Puerta | Evidencia mínima |
|---|---|
| Problema | Caso reciente y patrón |
| Impacto | Métrica o coste proxy |
| Prioridad | Motivo y fecha |
| Champion | Persona que moviliza datos y equipo |
| Aprobador | Persona que decide presupuesto |
| Firmante | Identificado |
| Técnica | Datos e integración viables |
| Éxito | Baseline, métrica y guardrails |
| Presupuesto | Fuente o proceso para crearlo |
| Competencia | Status quo y alternativas |

“Interesado” sin estas puertas permanece en discovery.

## Compromisos progresivos

1. conversación sobre un caso;
2. acceso al owner;
3. revisión de registros;
4. aceptación de baseline;
5. reunión con aprobador;
6. prueba técnica;
7. propuesta revisada en directo;
8. piloto pagado;
9. revisión de resultado;
10. contrato de continuidad.

Si una cuenta no acepta compromisos pequeños, una intención positiva no basta para pronosticar cierre.

## Plan de acción mutuo

Crear el plan antes de la propuesta:

| Hito | Dueño cliente | Dueño proveedor | Fecha | Salida |
|---|---|---|---|---|
| Baseline aceptado |  |  |  | Documento |
| Seguridad/datos |  |  |  | Aprobación |
| Alcance del piloto |  |  |  | SOW |
| Presupuesto |  |  |  | Confirmación |
| Contrato/DPA |  |  |  | Firma |
| Inicio |  |  |  | Kickoff |
| Revisión |  |  |  | Decisión |

Una fecha sin dueño no es un plan.

## Propuesta de piloto

Máximo cinco páginas o secciones:

1. **Situación:** hechos confirmados y baseline.
2. **Objetivo:** métrica principal, guardrails y umbral.
3. **Alcance:** flujo, usuarios, integración, entregables y exclusiones.
4. **Ejecución:** fases, responsables, soporte, seguridad y reversión.
5. **Comercial:** precio, impuestos, pago, vigencia y siguiente contrato posible.

Añadir supuestos y criterio de parada. No incluir una lista extensa de funcionalidades no discutidas.

## Precio

No hay evidencia para fijar un precio de mercado. Usar un proceso:

1. calcular coste real de implantación, soporte y terceros;
2. estimar valor conservador con datos del cliente;
3. definir un precio fijo por alcance;
4. probar disposición de pago en propuestas reales;
5. registrar descuento, razón y resultado;
6. revisar tras cinco propuestas y después de cada piloto.

Evitar cobrar solo por horas si se vende un resultado, pero asegurar que el precio cubre el trabajo manual inicial. No regalar pilotos para fabricar demanda.

## Revisión de propuesta

No “enviar y esperar”. Revisar con champion y aprobador:

1. ¿Qué hecho está mal?
2. ¿Qué resultado importa más?
3. ¿Qué riesgo impediría firmar?
4. ¿Quién más debe aprobar?
5. ¿De qué presupuesto sale?
6. ¿Qué ocurre si no se actúa?
7. ¿Qué fecha real manda?
8. ¿Qué paso y documento faltan?

Al final, acordar una acción fechada o cerrar la oportunidad.

## Preguntas de cierre

### Cierre de alcance

> Si limitamos el piloto a [flujo], [equipo] y [métrica], ¿queda fuera algo imprescindible para decidir?

### Cierre de decisión

> Si el piloto alcanza el umbral sin romper los guardrails, ¿qué decisión tomará y quién la aprobará?

### Cierre de proceso

> ¿Qué debe ocurrir entre esta reunión y la firma, en qué orden y con qué responsables?

### Cierre explícito

> Con alcance, precio, seguridad y fecha acordados, ¿están en posición de firmar el [fecha]? Si no, ¿cuál es el bloqueo concreto?

## Objeciones de cierre

### Precio

Separar:

- valor insuficiente;
- presupuesto inexistente;
- comparación con alternativa;
- riesgo de implantación;
- táctica de negociación.

No descontar antes de conocer cuál es. Cambiar precio a cambio de alcance, plazo, pago anticipado, menor soporte o derecho de caso aprobado; nunca por presión sin contrapartida.

### “Más adelante”

> ¿Qué evento hará que sea prioritario y en qué fecha se revisará? Si no existe evento, lo cierro como no prioritario.

### “Necesito hablar con mi socio”

> Incluyámoslo. ¿Qué criterio usará y qué objeción espera? No quiero que usted tenga que revender una propuesta que debemos explicar nosotros.

### “Piloto gratuito”

> Podemos hacer una conversación y prueba técnica acotada antes. El piloto usa datos, soporte y un resultado acordado; el pago valida prioridad. Si no hay presupuesto, no estamos aún en piloto.

### Riesgo técnico o de datos

Reducir alcance, usar datos anonimizados, entorno aislado y plan de reversión. Si el riesgo sigue siendo desproporcionado, no cerrar.

## Contrato mínimo

Revisión profesional según el caso:

- objeto, alcance y exclusiones;
- precio, impuestos, facturación y pago;
- propiedad intelectual y licencias;
- confidencialidad;
- protección de datos y DPA;
- subencargados y transferencias;
- seguridad e incidentes;
- niveles de servicio y soporte;
- aceptación de entregables;
- duración, terminación y salida;
- límites de responsabilidad;
- uso de nombre, métricas o caso de éxito;
- ley y jurisdicción.

No prometer cumplimiento jurídico del proceso inmobiliario como resultado automático del software.

## Después de la firma

El cierre comercial continúa con adopción:

1. kickoff con owner y usuarios;
2. baseline congelado;
3. formación por tarea;
4. seguimiento de uso y excepciones;
5. revisión intermedia;
6. informe final con aprobador;
7. decisión de continuar, ampliar, corregir o parar.

Registrar tiempo real y trabajo manual oculto para no vender un margen ficticio.

## Closed-lost

Usar una razón primaria:

- problema no prioritario;
- sin evidencia de impacto;
- sin presupuesto;
- sin acceso al aprobador;
- status quo suficiente;
- competidor;
- integración/datos;
- seguridad/legal;
- calendario;
- precio;
- pérdida de contacto;
- descalificación mutua.

Añadir evidencia y fecha de revisión. “No respondió” no explica la causa; es estado de contacto hasta que la oportunidad se cierre.
