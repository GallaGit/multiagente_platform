# 7. Cadena de valor

## Flujo de la operación

```text
Propietario / promotor
        ↓ mandato
Agencia captadora ───── Portales / MLS / marketing
        ↓                         ↓
   Información               Compradores/leads
        └──────────────┬──────────┘
                       ↓
             Visitas y negociación
                       ↓
 Banco / bróker → financiación → tasador
                       ↓
 Abogado / gestoría → revisión y contratos
                       ↓
                  Notario
                       ↓
          Registro / Catastro / impuestos
                       ↓
        Entrega y gestión posterior
```

## Actores y función

| Actor | Función |
|-------|---------|
| **Propietario** | Aporta el inmueble y fija límites del mandato |
| **Comprador** | Aporta demanda, fondos o financiación |
| **Agencia captadora** | Obtiene mandato y prepara el producto |
| **Agencia compradora** | Aporta demanda; puede compartir comisión |
| **Portales** | Agregan oferta y generan visibilidad |
| **CRM / proveedor tech** | Registra propiedades, contactos y actividad |
| **Fotógrafo / home stager** | Mejora presentación |
| **Banco** | Analiza solvencia y concede financiación |
| **Intermediario de crédito** | Tramita hipotecas; regulación específica |
| **Tasador** | Valoración homologada para financiación |
| **Notario** | Control legal y fe pública |
| **Registro** | Protege e inscribe derechos reales |
| **Catastro** | Descripción administrativa y fiscal |
| **Abogados / gestorías** | Due diligence, fiscalidad y trámites |
| **Arquitectos / técnicos** | Licencias, patologías y obras |
| **Constructoras / reformistas** | Creación o mejora física |
| **Aseguradoras** | RC profesional, caución, hogar e impago |
| **Property manager** | Gestiona el activo tras la compra |
| **Administración pública** | Urbanismo, vivienda, consumo, tributos |

La agencia coordina buena parte de la cadena, pero no sustituye funciones reservadas a notarios, tasadores, abogados o técnicos.
