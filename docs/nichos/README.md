# Nichos

Cada carpeta es un **pack de nicho**: investigación, oferta, spec de entrega y contexto que los agentes pueden inyectar.

El runtime solo carga el nicho activo (`ACTIVE_NICHE`, por defecto `inmobiliaria`) y los archivos listados en su `manifest.json`.

| Nicho | Estado | Entrada |
|---|---|---|
| [inmobiliaria](inmobiliaria/) | Activo | [README](inmobiliaria/README.md) |

No añadir otro nicho hasta validar venta, entrega y mantenimiento del actual.
