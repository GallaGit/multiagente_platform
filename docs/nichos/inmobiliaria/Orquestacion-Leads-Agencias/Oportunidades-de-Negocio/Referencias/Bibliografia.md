## Criterio bibliográfico

Las fuentes originales de cada dolor se conservan en su ficha D01–D30. Este archivo evita duplicar más de 90 referencias y enlaza los registros auditables. Las promesas de fabricante se usan para capacidad, no para resultado.

## Limitación

Las fichas de empresas y análisis prometidos por el Módulo 5 no existen todavía. Su README solo sustenta la composición de la muestra y la conclusión competitiva agregada.
