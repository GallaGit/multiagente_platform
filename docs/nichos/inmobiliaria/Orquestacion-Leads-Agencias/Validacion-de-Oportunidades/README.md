# Módulo 07 — Validación de oportunidades

**Fecha de corte:** 12 de agosto de 2026  
**Ámbito principal:** soluciones B2B para agencias inmobiliarias en España  
**Objetivo:** decidir qué oportunidades merecen entrevista, experimento, piloto o descarte mediante criterios comparables.

## Principio de trabajo

Una oportunidad no se elige por entusiasmo, novedad o preferencia tecnológica. Se evalúa con la misma matriz, la misma escala y evidencia trazable.

La puntuación sirve para ordenar decisiones; no convierte supuestos en hechos. Toda cifra debe indicar fuente, fecha y nivel de confianza.

## Salidas obligatorias

Cada oportunidad debe terminar con:

- una ficha de alcance;
- una matriz puntuada con evidencia;
- nivel de confianza;
- riesgos y condiciones eliminatorias;
- decisión y responsable;
- próximo experimento, si procede;
- fecha de revisión.

## Estado de una oportunidad

`Borrador → Por validar → En validación → Validada → Piloto → Priorizada`

Una oportunidad también puede pasar a `En espera`, `Descartada` o `Invalidada`. “Validada” significa que superó la evidencia definida; no que el producto vaya a tener éxito.
