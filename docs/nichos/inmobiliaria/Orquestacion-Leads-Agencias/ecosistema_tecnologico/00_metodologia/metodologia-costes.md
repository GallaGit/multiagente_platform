# Metodología de costes

**Corte:** agosto de 2026

---

## 1. Principio

**No se inventan cifras.** Solo se registran precios cuando existe página pública del fabricante, informe con metodología, o rango citado con fuente y fecha de consulta.

Si no hay dato público: **«no público / bajo presupuesto»**.

---

## 2. Componentes del coste tecnológico (TCO)

| Componente | Qué incluye | Observabilidad |
|------------|-------------|----------------|
| Licencia / SaaS | Usuario/mes, pack, módulos | A veces pública |
| Implantación | Setup, migración, formación | Suele ser presupuesto |
| Integraciones | API, iPaaS, desarrollo a medida | Variable |
| Canales | Portales, ads, WhatsApp Business API | Portales: **opacos** |
| Operación | Admin interno, soporte, tiempo de agentes | Rara vez cuantificado |
| Cumplimiento | Firma cualificada, KYC, backups, RGPD | Parcial |
| Cambio / salida | Export, re-captura, formación | Casi nunca publicado |

El coste dominante en muchas agencias **no es el CRM**, sino **portales + tiempo humano** en herramientas desconectadas. Evidencia cualitativa sectorial; cuantificación agregada **no pública**. **[Media-baja]**

## 4. Qué NO se hace en este informe

- No se estiman «precios medios de mercado» sin fuente.
- No se extrapolan packs de Idealista Gold / Fotocasa Premium a partir de blogs.
- No se usa el ROI 5,36:1 de `context.md`.
- No se confunde coste de software con coste total de adquisición de lead.

---

## 5. Cómo se presenta en las fichas

Cada categoría incluye, cuando exista:

- Modelo (SaaS / licencia / crédito / comisión)
- Precio público + URL + fecha
- Impuestos (si el fabricante indica «sin IVA»)
- Qué no está incluido (implantación, usuarios extra, API)

En [`07_analisis_transversal/costes-tco.md`](../07_analisis_transversal/costes-tco.md) se sintetiza el TCO por arquetipo **solo con componentes documentados** y se marca el resto como pendiente.
