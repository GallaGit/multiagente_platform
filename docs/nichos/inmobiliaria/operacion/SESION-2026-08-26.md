## 1. Baseline y métricas (código)

### API
- Filtro **`mvp_only=true`** (default) en `GET /leads`, `/leads/metrics`, `/leads/exceptions` — solo contactos con `lead_origen`.
- **`POST /leads/baseline`** y **`GET /leads/baseline`** — snapshot local en `data/baseline.json` (gitignored).
- **`GET /leads/metrics`** devuelve `{ current, baseline, delta }`.
- Campo **`mediana_tiempo_respuesta_min`** (null si n < 2 muestras con `primera_respuesta_at`).
- Módulo nuevo: `api/leads/baseline.py`.
- Tests: `tests/test_baseline.py` (5 casos). Suite total: **36 passed**.

### UI
- `KpiGrid`: tarjeta mediana 1ª respuesta + delta vs baseline por KPI.
- `LeadsPage`: botón **Capturar baseline**, fecha del snapshot, toggle **Incluir todos los contactos HubSpot**.
- `frontend/src/lib/api.ts`: tipos `MetricsDashboard`, `captureBaseline`, query `mvp_only`.

### Datos
- Plantilla: `data/baseline.example.json`.
- Baseline demo capturado en local (no commitear): 4 leads MVP, 50% responsable, 75% siguiente acción, 1 excepción.

## 4. Cómo reproducir (mañana)

```bash
# API
uvicorn api.main:app --reload --host 127.0.0.1 --port 8000

# UI
cd frontend && npm run dev

# Tests
python -m pytest

# Capturar baseline
curl -X POST http://127.0.0.1:8000/leads/baseline \
  -H "Content-Type: application/json" \
  -d '{"note":"Lab dia 0","mvp_only":true}'
```
